
# Como usar no Google Colab

1. Faça upload/clonagem da pasta `secaae_analista_v2`.
2. Abra `SECAAE_Analista_V2.ipynb`.
3. Execute as células na ordem.
4. Na célula de configuração, informe o `DRIVE_FOLDER_ID` e a `GEMINI_API_KEY`.
5. Execute a sincronização.
6. Inicie o Streamlit.

O notebook inclui uma opção de túnel com ngrok. O token do ngrok deve ser
informado como variável de ambiente e nunca gravado no código.
